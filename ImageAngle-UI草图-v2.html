1交互规则

  • 画好的线端点可拖拽，角度实时更新
  • 拖动参考线端点：全部已测牙角度重算
  • 列表行 ↔ 画布线条双向高亮联动
  • 重复测量同一牙位：覆盖 + 提示（无模态弹窗，可撤销）
  • 撤销（Ctrl+Z）按图保留历史，切图不丢

2测量规则（已定）

  • 牙长轴：根→冠，22% 根尖回退（显示约定，不影响角度值）
  • 未画参考线 → 输出空白结果，不计算角度
  • 未填牙位：按图像方向给临时符号并提示复核（*）
  • 角度归一化至 [−90°, +90°]，近中为正
  • 支持 JPG / JPEG / PNG / TIFF / BMP（v1 不含 DICOM）

3已定稿决策

  • 方向约定：放射学惯例（患者右侧=图像左侧）+ 镜像按钮，导出头记录
  • 未画参考线 → 空白结果；画参考线后自动补算并提示
  • 置信度：默认空，点击循环 高/中/低/空
  • 技术栈：Python + PySide6 + OpenCV
  • 参考线：腭中缝优先，类型下拉记录（腭中缝/竖直/其他）
  • 未填牙位：临时符号 + 提示；导出 note 注明
  • 重复测量：覆盖 + 提示 + 可撤销（无模态）· seq 每图重排
  • 22% 根尖回退：显示约定，比例可配置
