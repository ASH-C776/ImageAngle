近中倾斜 vs 远中倾斜

放射学惯例：看片时患者右侧在图像左侧 · FDI 四象限牙位法

参考线（基准方向）
牙长轴（根→冠）
近中方向（正角）
远中方向（负角）
一句话总结
近中（mesial）：牙冠朝中线方向倾斜 → 记为 正角（+）
远中（distal）：牙冠朝外侧（远离中线）方向倾斜 → 记为 负角（−）

为什么左右象限符号规则相反？
因为"近中"永远是朝中线。在图像左侧（右上1x / 右下4x），中线在右边，所以冠向右倒 = 近中 = 正；
在图像右侧（左上2x / 左下3x），中线在左边，所以冠向左倒 = 近中 = 正。

未填牙位时怎么办？
软件按牙根所在半侧给临时符号：左半侧默认"向右倒=正"，右半侧默认"向左倒=正"，并提示需人工确认。
