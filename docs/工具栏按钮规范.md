# 工具栏按钮规范

## 两类按钮

### 可激活工具（有选中态，可 toggle）
- 画参考线、画牙长轴
- 点一下进入该模式，按钮保持高亮；再点一次 / 按 Esc / 切到其他工具 → 取消高亮
- 画布模式与按钮选中态严格同步：
  - MODE_REF →「画参考线」亮
  - MODE_TOOTH →「画牙长轴」亮
  - MODE_NONE → 全灭

### 一次性动作（无选中态）
- 打开图片、打开文件夹、适应窗口、撤销、删除、上一张、下一张、导出 CSV
- 点一下执行一次，不保持状态
- 不可用时（无图片 / P2/P3/P4 阶段占位）变灰
- 「适应窗口」：图片放大 / 拖动后一键回到打开时的整图大小（缩放复位 + 居中）；
  卡片化后视觉上的「默认大小」就是整图适应画布，所以不叫「100%」（100% 是实际像素，Ctrl+1）
- 平移不再需要独立工具：画布内任意位置**按住鼠标中键拖拽**即可平移

## 快捷键
- 画参考线：R
- 画牙长轴：T
- Esc：取消当前画线
- Ctrl+0：适应窗口（回到整图大小）；Ctrl+1：实际像素 100%
- 鼠标：滚轮以光标为中心缩放；中键拖拽平移
