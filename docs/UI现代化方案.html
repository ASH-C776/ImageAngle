四、关键规则

角度数字颜色规则

  • 正角和负角都用主文字色（深色=#e5e5e5，浅色=#1a1a1a），靠 +/− 符号区分方向
  • 方向标签（近中/远中）用次文字色，灰色胶囊背景
  • 只有异常值（|角度|>30°）才用红色 danger 色
  • 不再用绿色/琥珀色区分正负，保持黑白灰统一

画布线条颜色

  • 参考线：浅灰虚线（深色=#d4d4d4，浅色=#1a1a1a）
  • 牙长轴：中灰实线（深色=#a3a3a3，浅色=#525252）
  • 选中线：提亮一档 + 加粗 0.5px
  • 画布背景：深色=#111，浅色=#f0f0f0（中性灰，不刺眼）

按钮规范

  • 纯图标按钮 30×30px，圆角 5px
  • 默认：透明底 + text-2 灰图标
  • hover：surface-2 底 + text 主色图标
  • 激活态：深色=白底黑图标 / 浅色=黑底白图标
  • 禁用：opacity 30%

主题切换

  • 工具栏最右侧加太阳/月亮图标按钮
  • 点击切换，所有颜色用变量驱动，平滑过渡 200ms
  • 选择持久化到 session.json，下次打开记住
  • 默认深色主题（医疗影像工具惯例）
